# Nexus Contract Intelligence

This repository contains the full-stack Nexus Contract Intelligence application.

## Project Structure

- `backend/` - Node.js/Express backend API
- `lexis-react/` - React frontend application

## Getting Started

### Backend

1. Open the `backend/` folder
2. Install dependencies with `npm install`
3. Start the server with `npm start`

### Frontend

1. Open the `lexis-react/` folder
2. Install dependencies with `npm install`
3. Start the app with `npm run dev`

## Tech Stack

- Backend: Node.js, Express, MongoDB
- Frontend: React, Vite
